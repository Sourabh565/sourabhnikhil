# College Attendance Management System — AI Build Package

## Stack
- Frontend: React + Vite
- Backend: Java 17 + Spring Boot
- Database: MySQL
- Authentication: Spring Security
- API: REST
- Selfie: Browser camera + multipart upload

## Documents
- backend.md — backend architecture, entities, schema, APIs, security and implementation order.
- frontend.md — UI pages, components, routes, camera feature, API integration and implementation order.
- integration.md — complete architecture, use cases, integration contract, security/privacy and AI workflow.

## Important Design Decision
The first version treats the selfie as evidence attached to an attendance submission. Automatic face recognition/identity verification is intentionally a later feature.

## Build Rule
Do not ask an AI coding tool to generate the entire application at once. Use the milestones in the documents, run the application after each milestone, and fix errors before continuing.
